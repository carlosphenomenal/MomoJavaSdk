# MTN MoMo Java SDK

A Java SDK for integrating with the MTN Mobile Money (MoMo) API. This SDK simplifies authentication, token management, and product interactions (like Collections) for both Sandbox and Live environments.

## Features
- **Flexible Sandbox Provisioning**: Provide your own `apiUser`. In Sandbox, the `apiKey` can be provided or auto-generated by the SDK.
- **Token Management**: Automatically handles access token retrieval and caching.
- **Utility Methods**: Helper methods to manually generate API users, API keys, and access tokens.
- **Easy-to-use API**: Simplified methods for common operations like `requestToPay`.
- **Environment Support**: Pre-configured for Sandbox and MTN Uganda.

## Quick Start (Sandbox Environment)

In the Sandbox environment, the SDK requires an `apiUser`. If you don't have one, you can generate it using the SDK (see [Manual Credential Generation](#manual-credential-generation)). If you leave the `apiKey` null during initialization in Sandbox, the SDK will attempt to auto-provision it for that session.

**Note:** The `apiKey` is optional in Sandbox if you have already generated one, but it is perfectly fine to leave it out, and the SDK will handle it.

```java
import io.github.carlosphenomenal.MomoMerchant;
import io.github.carlosphenomenal.Enums.TargetEnvironment;
import io.github.carlosphenomenal.Products.MomoCollections;
import io.github.carlosphenomenal.Types.TypeUniqueSet;
import io.github.carlosphenomenal.Dtos.PaymentRequest;
import io.github.carlosphenomenal.Enums.PartyIdType;

public class Main {
    public static void main(String[] args) {
        // 1. Initialize the Merchant with Sandbox environment
        // You must provide apiUser. The apiKey will be generated 
        // if not provided (only in Sandbox).
        MomoMerchant merchant = MomoMerchant.builder()
                .targetEnvironment(TargetEnvironment.SANDBOX)
                .apiUser("YOUR_SANDBOX_API_USER") // Required
                .products(TypeUniqueSet.of(new MomoCollections("YOUR_SANDBOX_SUBSCRIPTION_KEY")))
                .build();

        // 2. Prepare a Payment Request
        PaymentRequest request = PaymentRequest.builder()
                .amount("100")
                .externalId("6353636")
                .payer(new PaymentRequest.Payer(PartyIdType.MSISDN, "256770000000"))
                .payerMessage("Payment for goods")
                .payeeNote("Thank you for shopping")
                .build();

        // 3. Request Client to Pay
        String referenceId = java.util.UUID.randomUUID().toString();
        String resultId = merchant.requestClientToPay(request, referenceId);
        
        System.out.println("Payment initiated. Reference ID: " + resultId);
    }
}
```

## Live Environment Configuration

For Live environments (e.g., `MTN_UGANDA`), you must provide your production `apiUser` and `apiKey` obtained from the MTN MoMo Developer portal.

```java
MomoMerchant merchant = MomoMerchant.builder()
        .targetEnvironment(TargetEnvironment.MTN_UGANDA)
        .apiUser("YOUR_PRODUCTION_API_USER")
        .apiKey("YOUR_PRODUCTION_API_KEY")
        .products(TypeUniqueSet.of(new MomoCollections("YOUR_PRODUCTION_SUBSCRIPTION_KEY")))
        .build();
```

### How to get credentials:
1. **Subscription Key**: Found in your profile on the MoMo Developer portal.
2. **API User**: A UUID created via the `/apiuser` endpoint.
3. **API Key**: Generated for a specific `apiUser` via the `/apiuser/{apiUserId}/apikey` endpoint.

## Usage Guide

### Request to Pay (Collections)
Initiates a transaction to deduct money from a subscriber's wallet.

**Note on Reference ID:** You can provide a custom UUID as the `referenceId`. If you leave it `null`, the SDK will automatically generate a unique UUID for the transaction.

```java
// Option 1: Provide your own reference ID
String referenceId = UUID.randomUUID().toString();
merchant.requestClientToPay(paymentRequest, referenceId);

// Option 2: Let the SDK generate one for you
String generatedId = merchant.requestClientToPay(paymentRequest, null);
```

### Check Payment Status
Checks the current status of a previously initiated transaction. The `referenceId` provided **must** be the same one used (or returned) during the `requestClientToPay` call.

```java
import io.github.carlosphenomenal.Dtos.PaymentStatus;

// Use the referenceId from a previous requestClientToPay call
PaymentStatus status = merchant.checkPaymentStatus("THE_REFERENCE_ID_USED_IN_REQUEST");
System.out.println("Transaction Status: " + status.getStatus());
```

Possible statuses include: `PENDING`, `SUCCESSFUL`, `FAILED`.

## Manual Credential Generation

If you prefer to handle credential generation manually, the SDK provides utility classes to help you get started.

### Generate Sandbox API User
```java
import io.github.carlosphenomenal.Provisioners.SandboxProvisioner;
import java.net.http.HttpClient;

HttpClient client = HttpClient.newHttpClient();
String apiUser = SandboxProvisioner.createApiUser(client, "YOUR_SUBSCRIPTION_KEY");
System.out.println("New API User: " + apiUser);
```

### Generate Sandbox API Key
```java
String apiKey = SandboxProvisioner.generateApiKey(client, "YOUR_API_USER", "YOUR_SUBSCRIPTION_KEY");
System.out.println("New API Key: " + apiKey);
```

### Fetch Access Token
If you just need an access token for a specific product:
```java
import io.github.carlosphenomenal.Provisioners.AccessTokenProvisioner;
import io.github.carlosphenomenal.Dtos.MomoTokenResponse;

MomoTokenResponse tokenResponse = AccessTokenProvisioner.fetchNewToken(
    client, 
    new MomoCollections("YOUR_SUBSCRIPTION_KEY"), 
    TargetEnvironment.SANDBOX, 
    "YOUR_API_USER", 
    "YOUR_API_KEY"
);
System.out.println("Access Token: " + tokenResponse.getAccessToken());
```

## Error Handling

The SDK throws `RuntimeException` or `IllegalArgumentException` for common errors:
- **Missing Credentials**: If you fail to provide an `apiKey` in production.
- **Product Not Registered**: If you try to use `MomoCollections` methods without adding it to the `products` set during initialization.
- **API Errors**: If the MTN API returns a non-success status code (e.g., 401 Unauthorized, 400 Bad Request).

Example:
```java
try {
    merchant.requestClientToPay(request, referenceId);
} catch (RuntimeException e) {
    System.err.println("Failed to process payment: " + e.getMessage());
}
```
